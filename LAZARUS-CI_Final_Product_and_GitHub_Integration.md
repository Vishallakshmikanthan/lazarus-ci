## 1. The one-paragraph picture

You create a small **public demo repo** (`campus-api-demo`) with a GitHub Actions pipeline (lint, test, build). A script breaks it (a bad dependency pin, a regression, a wrong Python version, a Dockerfile typo, a missing secret). **The pipeline goes red on GitHub.** n8n notices within seconds, wakes Lazarus, and pings Telegram. Lazarus reads the failed job logs, writes three competing hypotheses, runs a read-only experiment for each, keeps or drops each one with evidence, then **opens a Pull Request with the fix**. **GitHub Actions runs on that PR, which is the rehearsal.** An independent verifier checks the result. Low-risk fixes merge on their own; risky ones (workflow files, secrets, test changes) wait for you to tap **Approve** in Telegram or on the dashboard. After the merge, `main` goes **green**. If the problem needs a human (a missing secret), Lazarus escalates with a handoff report instead of hacking around it.

**The headline visual for the jury: a red X on GitHub Actions turning into a green check, with the agent's reasoning shown live next to it.**

## 3. The insight data (what the numbers mean and where they come from)

Everything below is computed from the **event timeline Lazarus already records**, so you never hand-type a number.

| Insight | Definition | Source events |
|---|---|---|
| **MTTR** | Resolved-run completion time minus the failed run's completion time (real GitHub timestamps) | `alert.failed_at`, `resolved` |
| **Time breakdown** | detect, diagnose, author fix, CI rehearsal, approval wait, merge to green | `alert, verdicts, pr_opened, verify, approval_request/approval, merged, resolved` |
| **Hypotheses scoreboard** | tested / rejected / confirmed / symptom-only per incident | `hypotheses`, `verdicts` |
| **Confidence + risk** | model confidence (0 to 1) and policy risk level | `verdicts`, `risk` |
| **Decision ledger** | who decided each gate: *policy* (risk gate), *human* (approval), *CI* (rehearsal) | `risk`, `approval`, `verify` |
| **Autonomy mix** | auto-resolved vs human-approved vs escalated | `resolved`, `approval`, `escalated` |
| **CI cycles per fix** | number of PR CI runs needed (1 = fixed first try) | `pr_opened`, `verify` |
| **Safety record** | actions blocked, test-tampering attempts caught, approvals requested | `plan`, `risk` |
| **Benchmark** | Lazarus vs naive agent, same environment (from the implementation plan, Module 8) | `bench.py` output |

### `lazarus/insights.py`
```python
from datetime import datetime


def _first(events, kind):
    return next((e for e in events if e["kind"] == kind), None)


def _last(events, kind):
    return next((e for e in reversed(events) if e["kind"] == kind), None)


def _epoch(iso):
    return datetime.fromisoformat(iso.replace("Z", "+00:00")).timestamp()


def incident_insights(inc):
    ev = inc["events"]
    alert, verdicts = _first(ev, "alert"), _last(ev, "verdicts")
    pr, verify = _first(ev, "pr_opened"), _last(ev, "verify")
    ar, ap = _last(ev, "approval_request"), _last(ev, "approval")
    merged, resolved = _last(ev, "merged"), _last(ev, "resolved")
    t = lambda e: e["ts"] if e else None
    d = lambda a, b: round(b - a, 1) if a is not None and b is not None else None
    failed_at = _epoch(alert["payload"]["failed_at"]) if alert and alert["payload"].get("failed_at") else None
    hy = [v for e in ev if e["kind"] == "verdicts" for v in (e["payload"].get("verdicts") or [])]
    count = lambda name: sum(1 for v in hy if v.get("verdict") == name)
    risk = _last(ev, "risk")
    return {
        "id": inc["id"], "outcome": inc["status"],
        "autonomy": "escalated" if inc["status"] == "escalated" else ("human_approved" if ap else "auto"),
        "mttr_s": d(failed_at, t(resolved)),
        "breakdown_s": {
            "detect": d(failed_at, t(alert)), "diagnose": d(t(alert), t(verdicts)),
            "author_fix": d(t(verdicts), t(pr)), "ci_rehearsal": d(t(pr), t(verify)),
            "approval_wait": d(t(ar), t(ap)) if ar and ap else 0, "merge_to_green": d(t(merged), t(resolved))},
        "hypotheses": {"tested": len(hy), "rejected": count("rejected"), "confirmed": count("confirmed"),
                       "symptom_only": count("symptom_only")},
        "confidence": (verdicts or {}).get("payload", {}).get("confidence"),
        "risk": (risk or {}).get("payload", {}).get("level"),
        "ci_cycles": sum(1 for e in ev if e["kind"] == "pr_opened" or e["kind"] == "verify"),
    }


def fleet_insights(incidents):
    rows = [incident_insights(i) for i in incidents]
    n = len(rows) or 1
    done = [r["mttr_s"] for r in rows if r["mttr_s"]]
    return {"incidents": len(rows), "resolved": sum(r["outcome"] == "resolved" for r in rows),
            "escalated": sum(r["outcome"] == "escalated" for r in rows),
            "autonomy": {k: sum(r["autonomy"] == k for r in rows) for k in ("auto", "human_approved", "escalated")},
            "avg_mttr_s": round(sum(done) / len(done), 1) if done else None}
```
Add to `server.py`:

```python
            "fleet": insights.fleet_insights(incs)}
```

### 4.2 The five faults (and what Lazarus should do)

| Fault | What breaks | Expected Lazarus behaviour | Risk policy outcome |
|---|---|---|---|
| `deps` | `requests==99.0.0` in requirements.txt | Pin a real version in a PR | **low**, auto-merge |
| `regression` | `pct / 100` becomes `pct / 10` in pricing.py; `test_discount` fails | Read the traceback, fix the source line in a PR | **medium**, auto-merge |
| `dockerfile` | `COPY requirments.txt .` typo; `build` fails | Fix the typo in a PR | **medium**, auto-merge |
| `pyversion` | Workflow `python-version` set to `"3.6"` | Fix the workflow in a PR | **high** (touches `.github/`), **needs approval** |
| `secret` | A new test needs `PAYMENT_API_KEY`, which is not set | **Escalate** with handoff; do NOT weaken the test | n/a, human action required |

The last two give you the approval demo and the escalation demo naturally. The mandatory PS-12 behaviours ("page a human when too risky or when the fix fails") are exercised by real faults.

### 4.3 `scripts/gh_break.py` (fault injector, plus reset)

```python
"""Usage: python scripts/gh_break.py <deps|regression|dockerfile|pyversion|secret>   |   python scripts/gh_break.py --reset"""
import sys
from pathlib import Path
from lazarus import gh

PRISTINE = Path(__file__).resolve().parents[1] / "demo_repo_src"      # local copy of the green repo files

FAULTS = {
    "deps": [("requirements.txt", "requests==2.32.3", "requests==99.0.0")],
    "regression": [("app/pricing.py", "(1 - pct / 100)", "(1 - pct / 10)")],
    "dockerfile": [("Dockerfile", "COPY requirements.txt .", "COPY requirments.txt .")],
    "pyversion": [(".github/workflows/ci.yml", 'python-version: "3.12"', 'python-version: "3.6"')],
    "secret": [(".github/workflows/ci.yml", "APP_ENV: ci", "APP_ENV: ci\n      PAYMENT_API_KEY: ${{ secrets.PAYMENT_API_KEY }}")],
}
NEW_FILES = {"secret": {"tests/test_config.py":
    'import os\n\n\ndef test_payment_key_present():\n    assert os.environ.get("PAYMENT_API_KEY")\n'}}


def commit(path, content, msg):
    try:
        _, sha = gh.get_file(path, "main")
    except Exception:
        sha = None
    gh.put_file(path, content, msg, "main", sha)


def break_repo(name):
    for path, old, new in FAULTS[name]:
        text, sha = gh.get_file(path, "main")
        assert old in text, f"{path}: pattern for '{name}' not found (already broken?)"
        gh.put_file(path, text.replace(old, new), f"chore: update {Path(path).name} (demo fault: {name})", "main", sha)
    for path, content in NEW_FILES.get(name, {}).items():
        commit(path, content, f"test: add {Path(path).name} (demo fault: {name})")
    print("broke:", name, "- watch the Actions tab go red")


def reset():
    for p in PRISTINE.rglob("*"):
        if p.is_file():
            commit(str(p.relative_to(PRISTINE)).replace("\\", "/"), p.read_text(), "chore: reset demo repo")
    try:                                                    # remove the fault-only test file
        _, sha = gh.get_file("tests/test_config.py", "main")
        gh.api("DELETE", "/contents/tests/test_config.py", json={"message": "chore: reset", "sha": sha, "branch": "main"})
    except Exception:
        pass
    for pr in gh.api("GET", "/pulls", params={"state": "open"}):          # close stale Lazarus PRs and branches
        if pr["head"]["ref"].startswith("lazarus/"):
            gh.api("PATCH", f"/pulls/{pr['number']}", json={"state": "closed"})
            try:
                gh.api("DELETE", f"/git/refs/heads/{pr['head']['ref']}")
            except Exception:
                pass
    print("reset done")


if __name__ == "__main__":
    reset() if sys.argv[1] == "--reset" else break_repo(sys.argv[1])
```

### 5.1 `lazarus/gh.py` (GitHub REST client)
```python
import base64
import os
import re
import time
import httpx

TOKEN = os.getenv("GITHUB_TOKEN", "")
REPO = os.getenv("GITHUB_REPO", "")
_c = httpx.Client(base_url="https://api.github.com", timeout=60, follow_redirects=True,
                  headers={"Authorization": f"Bearer {TOKEN}", "Accept": "application/vnd.github+json",
                           "X-GitHub-Api-Version": "2022-11-28"})


def api(method, path, **kw):
    r = _c.request(method, f"/repos/{REPO}{path}", **kw)
    r.raise_for_status()
    return r.json() if r.content else {}


def get_file(path, ref="main"):
    j = api("GET", f"/contents/{path}", params={"ref": ref})
    return base64.b64decode(j["content"]).decode(), j["sha"]


def put_file(path, content, message, branch, sha=None):
    body = {"message": message, "content": base64.b64encode(content.encode()).decode(), "branch": branch}
    if sha:
        body["sha"] = sha
    return api("PUT", f"/contents/{path}", json=body)


def branch_sha(branch="main"):
    return api("GET", f"/git/ref/heads/{branch}")["object"]["sha"]


def create_branch(name, base="main"):
    try:
        api("POST", "/git/refs", json={"ref": f"refs/heads/{name}", "sha": branch_sha(base)})
    except httpx.HTTPStatusError as e:
        if e.response.status_code != 422:          # 422 = branch already exists
            raise


def jobs(run_id):
    return api("GET", f"/actions/runs/{run_id}/jobs")["jobs"]


def job_log(job_id):
    r = _c.get(f"/repos/{REPO}/actions/jobs/{job_id}/logs")
    return r.text if r.status_code == 200 else ""


def wait_run(sha, timeout=300):
    t0 = time.time()
    while time.time() - t0 < timeout:
        rs = api("GET", "/actions/runs", params={"head_sha": sha, "per_page": 5})["workflow_runs"]
        done = [r for r in rs if r["status"] == "completed"]
        if done:
            return done[0]
        time.sleep(4)
    raise TimeoutError("CI did not finish in time")


_TS = re.compile(r"^\d{4}-\d\d-\d\dT[\d:.]+Z\s?")
_ERR = re.compile(r"(error|failed|fatal|no matching distribution|not found|assert|exception|denied)", re.I)


def clean(text):
    return [_TS.sub("", ln) for ln in text.splitlines() if not ln.startswith(("##[group]", "##[endgroup]"))]


def extract_errors(text, n=8):
    out = []
    for ln in clean(text):
        s = ln.strip()[:240]
        if s and _ERR.search(s) and s not in out:
            out.append(s)
    return out[:n]
```

```python
    def __init__(self):
        self.branch = self.pr = self.pr_url = self.run_url = self.failed_at = None
        self.run_id = self.main_sha = self.head_sha = None
        self.last_diff, self.job_ids, self.obs = "", {}, {}

    # ---- helpers
    def _read(self, path, ref):
        try:
            return gh.get_file(path, ref)[0]
        except Exception:
            return ""

    def _ref(self):
        return self.branch or "main"

    def _build_obs(self, run):
        js = gh.jobs(run["id"])
        self.job_ids = {j["name"]: j["id"] for j in js}
        failed = next((j for j in js if j["conclusion"] == "failure"), None)
        text = gh.job_log(failed["id"]) if failed else ""
        return {
            "pipeline_status": "passed" if run["conclusion"] == "success" else ("failed" if run["conclusion"] else "running"),
            "current_stage": failed["name"] if failed else "",
            "pipeline_stages": {j["name"]: STAGE.get(j["conclusion"] or j["status"], "pending") for j in js},
            "surfaced_errors": gh.extract_errors(text),
            "visible_alerts": [f'{run["name"]} #{run["run_number"]} {run["conclusion"]} on {run["head_branch"]}'],
            "visible_logs": gh.clean(text)[-60:], "findings": [],
            "config_files": {p: self._read(p, run["head_sha"]) for p in WATCH},
            "available_tools": ["view_logs", "inspect_config", "modify_config", "add_dependency", "rerun_pipeline", "finalize"],
            "destructive_actions": 0, "incident_resolved": False,
        }

    # ---- OpenEnv-style interface
    def reset(self, run_id=None, **kw):
        if run_id:
            run = gh.api("GET", f"/actions/runs/{run_id}")
        else:
            runs = gh.api("GET", "/actions/runs", params={"branch": "main", "status": "failure", "per_page": 1})["workflow_runs"]
            if not runs:
                raise RuntimeError("no failed run on main")
            run = runs[0]
        self.run_id, self.run_url, self.failed_at = run["id"], run["html_url"], run["updated_at"]
        self.main_sha = self.head_sha = run["head_sha"]
        self.obs = self._build_obs(run)
        return self.obs

    def step(self, operation, target="", value=""):
        if operation in ("view_logs", "tail_logs"):
            jid = self.job_ids.get(target) or next(iter(self.job_ids.values()), None)
            text = gh.job_log(jid) if jid else ""
            o = dict(self.obs, visible_logs=gh.clean(text)[-80:], surfaced_errors=gh.extract_errors(text))
            return o
        if operation in ("inspect_config", "inspect_dockerfile", "inspect_permissions"):
            self.obs["config_files"] = {**self.obs["config_files"], target: self._read(target, self._ref())}
            return self.obs
        if operation == "set_hypothesis":
            return self.obs
        if operation == "modify_config":
            self._commit(target, value)
            return self.obs
        if operation == "add_dependency":
            return self.step("modify_config", target or "requirements.txt", self._with_dependency(target or "requirements.txt", value))
        if operation == "rerun_pipeline":
            return self._ci_on_branch()
        if operation == "verify_fix":
            return self.obs
        if operation == "finalize":
            return self._merge()
        raise ValueError(f"unsupported operation {operation}")

    # ---- fix + rehearsal + merge
    def _with_dependency(self, path, spec):
        text = self._read(path, self._ref())
        name = spec.split("==")[0].strip().lower()
        lines = [spec if ln.lower().startswith(name) else ln for ln in text.splitlines()]
        if spec not in lines:
            lines.append(spec)
        return "\n".join(lines) + "\n"

    def _commit(self, path, content):
        if not self.branch:
            self.branch = f"lazarus/fix-{self.run_id}"
            gh.create_branch(self.branch)
        old = self._read(path, self._ref())
        try:
            sha = gh.get_file(path, self.branch)[1]
        except Exception:
            sha = None
        resp = gh.put_file(path, content, f"fix({path}): Lazarus-CI automated repair", self.branch, sha)
        self.head_sha = resp["commit"]["sha"]
        self.last_diff += "".join(difflib.unified_diff(old.splitlines(True), content.splitlines(True),
                                                       f"a/{path}", f"b/{path}"))

    def _ci_on_branch(self):
        if not self.pr:
            pr = gh.api("POST", "/pulls", json={"title": f"Lazarus-CI repair for run #{self.run_id}", "head": self.branch,
                                                "base": "main", "body": "Opened by Lazarus-CI. Details below."})
            self.pr, self.pr_url = pr["number"], pr["html_url"]
        self.obs = self._build_obs(gh.wait_run(self.head_sha))
        return self.obs

    def set_pr_body(self, text, labels=None):
        if self.pr:
            gh.api("PATCH", f"/pulls/{self.pr}", json={"body": text})
            if labels:
                try:
                    gh.api("POST", f"/issues/{self.pr}/labels", json={"labels": labels})
                except Exception:
                    pass

    def _merge(self):
        gh.api("PUT", f"/pulls/{self.pr}/merge", json={"merge_method": "squash"})
        run = gh.wait_run(gh.branch_sha("main"))
        o = self._build_obs(run)
        o["incident_resolved"] = run["conclusion"] == "success"
        self.obs = o
        return o

    def abandon(self):
        if self.pr:
            gh.api("PATCH", f"/pulls/{self.pr}", json={"state": "closed"})
```

**Known weak spots:**
- `wait_run` may find nothing for a few seconds after a commit. It simply keeps polling.
- A fix that makes a *different* job fail comes back as a new failed PR run; the agent loop treats that as another attempt.
- If the `build` job is slow on your repo, shorten it or drop it.

### 5.3 `lazarus/risk_gh.py` (the policy that gates the **merge**)

The branch and PR are safe by construction: reversible and tested by CI before anything touches `main`. **The merge is the gated action.**

```python
import re

ALLOWED = {"modify_config", "add_dependency"}
SENSITIVE = re.compile(r"(secret|password|token|credential|api[_-]?key|permission|\biam\b|terraform|\.env\b)", re.I)


def assess(fix: dict, confidence: float, diff: str = "") -> dict:
    op, path = fix.get("operation", ""), fix.get("target", "")
    if op not in ALLOWED:
        return {"level": "blocked", "needs_approval": True, "reasons": [f"operation '{op}' is not allowed"]}
    level, reasons = ("low" if op == "add_dependency" else "medium"), []
    if path.startswith(".github/"):
        level = "high"; reasons.append("changes CI/CD workflow definitions")
    if path.startswith("tests/"):
        level = "high"; reasons.append("modifies tests (possible test tampering to force green)")
    if SENSITIVE.search(path) or (not path.startswith(".github/") and SENSITIVE.search(fix.get("value", ""))):
        level = "high"; reasons.append("touches secrets / credentials / permissions")
    changed = sum(1 for l in diff.splitlines() if l[:1] in "+-" and not l.startswith(("+++", "---")))
    if changed > 40:
        reasons.append(f"large diff ({changed} changed lines)")
        level = "medium" if level == "low" else level
    if confidence < 0.6:
        reasons.append(f"low confidence ({confidence:.2f} < 0.60)")
    return {"level": level, "needs_approval": level == "high" or confidence < 0.6, "reasons": reasons}
```

### 5.4 `lazarus/agent_gh.py` (the PR-based incident loop)

It reuses `SYSTEM`, `digest`, `hypotheses`, and `READ_ONLY` from `agent.py` (implementation plan, Module 2).

```python
import json
from .agent import SYSTEM, digest, hypotheses
from .llm import ask_json, LLMError
from . import risk_gh, verifier, telegram_bot

MAX_ATTEMPTS = 3

JUDGE_RULES = (
    "TASK: give each hypothesis a verdict (confirmed | rejected | symptom_only | inconclusive) citing concrete evidence. "
    "Separate CAUSE from SYMPTOM. Choose ONE minimal fix for the confirmed root cause.\n"
    "For modify_config, `value` MUST be the COMPLETE new content of the file `target` (not a diff). For add_dependency, "
    "`target` is the requirements file and `value` is `package==version` using a REAL released version.\n"
    "HARD RULES: never delete or weaken tests to make CI pass; never invent or expose secrets/credentials; never disable CI steps. "
    "If the root cause needs a human action (missing secret, permissions, infrastructure), set `fix` to null and put the exact "
    "human action in `human_action`.\n"
    'Return {"verdicts":[{"id":"H1","verdict":"...","evidence":"..."}],"root_cause":"...","confidence":0.0,'
    '"fix":{"operation":"modify_config","target":"path","value":"..."}|null,"human_action":"...","reasoning":"..."}')


def judge_gh(obs, hyps, results, excluded):
    user = (f"INITIAL EVIDENCE:\n{json.dumps(digest(obs, 15), indent=1)}\n\nHYPOTHESES:\n{json.dumps(hyps)}\n\n"
            f"EXPERIMENT RESULTS:\n{json.dumps(results, indent=1)[:9000]}\n\n"
            f"Already tried and failed (do not repeat): {excluded}\n\n{JUDGE_RULES}")
    return ask_json(SYSTEM, user)


def pr_body(inc_events, v, assess, verify_res, inc):
    hy = next((e["payload"]["hypotheses"] for e in reversed(inc_events) if e["kind"] == "hypotheses"), [])
    ver = {x["id"]: x for x in (v.get("verdicts") or [])}
    rows = "\n".join(f'| {h["id"]} | {h["statement"]} | {h["action"]["operation"]} ({h["action"].get("target","")}) | '
                     f'{ver.get(h["id"], {}).get("verdict", "?").upper()} | {ver.get(h["id"], {}).get("evidence", "")} |' for h in hy)
    return (f"## Root cause (confidence {v.get('confidence')})\n{v.get('root_cause')}\n\n"
            f"## Hypotheses tested\n| # | Hypothesis | Experiment | Verdict | Evidence |\n|---|---|---|---|---|\n{rows}\n\n"
            f"## Risk policy\n{assess['level'].upper()}: " + ("; ".join(assess["reasons"]) or "no sensitive paths touched") +
            f"\n\n## Verification\nCI rehearsal on this PR: {verify_res['verdict'].upper()} "
            f"({verify_res['stages_passed_after']}/{verify_res['stages_total']} jobs passed)\n\n"
            f"_Opened automatically by Lazarus-CI, incident #{inc}._")


def run_incident_gh(inc, env, store, wait_for_approval, run_id=None):
    emit = lambda k, **p: store.emit(inc, k, **p)
    try:
        obs = env.reset(run_id=run_id)
        emit("alert", run_url=env.run_url, failed_at=env.failed_at, stage=obs["current_stage"],
             errors=obs["surfaced_errors"][:4])
        store.set_stages(inc, obs["pipeline_stages"])
        excluded, v, assess, res = [], {}, {}, {}
        for attempt in range(1, MAX_ATTEMPTS + 1):
            before = obs
            obs = env.step("view_logs", obs.get("current_stage", ""))
            emit("triage", attempt=attempt, errors=obs["surfaced_errors"][:4])
            hyps = hypotheses(obs, excluded)
            emit("hypotheses", attempt=attempt, hypotheses=hyps)
            results = {}
            for h in hyps:
                o2 = env.step(h["action"]["operation"], h["action"].get("target", ""))
                results[h["id"]] = {"action": h["action"], "errors": o2["surfaced_errors"][:5],
                                    "logs": o2["visible_logs"][-10:],
                                    "config": {k: str(x)[:800] for k, x in o2["config_files"].items()}}
                emit("experiment", hypothesis=h["id"], action=h["action"], errors=o2["surfaced_errors"][:3])
                obs = o2
            v = judge_gh(obs, hyps, results, excluded)
            emit("verdicts", attempt=attempt, verdicts=v.get("verdicts"), root_cause=v.get("root_cause"),
                 confidence=v.get("confidence"))
            fix = v.get("fix")
            if not fix:
                return _escalate(inc, store, emit, env, f"needs a human action: {v.get('human_action') or v.get('root_cause')}", v)
            emit("plan", fix={"operation": fix["operation"], "target": fix.get("target")})
            env.step("set_hypothesis", "", v.get("root_cause", ""))
            env.step(fix["operation"], fix.get("target", ""), fix.get("value", ""))
            emit("fix_committed", branch=env.branch, file=fix.get("target"), diff=env.last_diff[-3000:])
            obs = env.step("rerun_pipeline")                   # opens the PR; GitHub CI is the rehearsal
            emit("pr_opened", pr=env.pr, url=env.pr_url)
            store.set_stages(inc, obs["pipeline_stages"])
            res = verifier.verify(before, obs)
            emit("verify", attempt=attempt, **res)
            if res["verdict"] == "passed":
                break
            excluded.append(f'{fix.get("operation")}:{fix.get("target")}')
        else:
            env.abandon()
            return _escalate(inc, store, emit, env, f"CI still failing after {MAX_ATTEMPTS} attempts", v)

        # ---- risk gate sits on the MERGE
        assess = risk_gh.assess(fix, float(v.get("confidence", 0)), env.last_diff)
        emit("risk", **assess)
        events = store.INCIDENTS[inc]["events"]
        env.set_pr_body(pr_body(events, v, assess, res, inc), [f"risk:{assess['level']}", "lazarus-ci"])
        if assess["level"] == "blocked":
            env.abandon()
            return _escalate(inc, store, emit, env, "fix blocked by policy", v)
        if assess["needs_approval"]:
            emit("approval_request", pr=env.pr, url=env.pr_url, fix=fix.get("target"), reasons=assess["reasons"],
                 root_cause=v.get("root_cause"), diff=env.last_diff[-1500:])
            telegram_bot.send(
                f"⚠️ APPROVAL NEEDED — PR #{env.pr}\nRoot cause: {v.get('root_cause')}\nFix: {fix.get('target')}\n"
                f"Risk: {assess['level'].upper()} — {'; '.join(assess['reasons'])}\nCI rehearsal on the PR: PASSED\n{env.pr_url}",
                telegram_bot.approval_buttons(inc))
            decision = wait_for_approval(inc)
            emit("approval", approved=decision)
            if not decision:
                env.abandon()
                return _escalate(inc, store, emit, env, "human rejected or did not answer", v)
        obs = env.step("finalize")                              # squash-merge, then wait for main's CI
        emit("merged", pr=env.pr)
        if obs["incident_resolved"]:
            emit("resolved", run_url=env.run_url, pr_url=env.pr_url)
            store.set_stages(inc, obs["pipeline_stages"])
            store.finish(inc, "resolved")
            telegram_bot.send(f"✅ RESOLVED\nPR #{env.pr} merged · main is green again\nRisk: {assess['level'].upper()}\n{env.pr_url}")
            return "resolved"
        return _escalate(inc, store, emit, env, "merged, but main is still red", v)
    except LLMError as e:
        return _escalate(inc, store, emit, env, f"LLM unavailable: {e}", {})
    except Exception as e:
        emit("error", error=str(e))
        return _escalate(inc, store, emit, env, f"unexpected error: {e}", {})


def _escalate(inc, store, emit, env, reason, v):
    handoff = store.build_handoff(inc, reason, v)
    emit("escalated", reason=reason, handoff=handoff)
    store.finish(inc, "escalated", handoff=handoff)
    telegram_bot.send(f"🆘 ESCALATED — Lazarus cannot safely fix this\n{reason}\n"
                      f"Root cause (best guess): {(v or {}).get('root_cause')}\nDashboard incident #{inc}")
    return "escalated"
```

### 5.5 `lazarus/telegram_bot.py` (messages + tappable Approve/Reject, no public URL needed)

```python
import os
import threading
import time
import httpx

TOKEN, CHAT = os.getenv("TELEGRAM_TOKEN", ""), os.getenv("TELEGRAM_CHAT_ID", "")


def _api(m):
    return f"https://api.telegram.org/bot{TOKEN}/{m}"


def enabled():
    return bool(TOKEN and CHAT)


def send(text, buttons=None):
    if not enabled():
        return
    body = {"chat_id": CHAT, "text": text, "disable_web_page_preview": True}
    if buttons:
        body["reply_markup"] = {"inline_keyboard": [buttons]}
    try:
        httpx.post(_api("sendMessage"), json=body, timeout=8)
    except Exception:
        pass


def approval_buttons(inc):
    return [{"text": "✅ Approve & merge", "callback_data": f"approve:{inc}"},
            {"text": "⛔ Reject", "callback_data": f"reject:{inc}"}]


def _poll(on_decision):
    offset = 0
    while True:
        try:
            r = httpx.get(_api("getUpdates"), params={"timeout": 20, "offset": offset}, timeout=30).json()
            for u in r.get("result", []):
                offset = u["update_id"] + 1
                cq = u.get("callback_query")
                if not cq or str(cq["message"]["chat"]["id"]) != str(CHAT):    # only YOUR chat can approve
                    continue
                action, inc = cq["data"].split(":")
                on_decision(int(inc), action == "approve")
                httpx.post(_api("answerCallbackQuery"), json={"callback_query_id": cq["id"], "text": "Recorded"}, timeout=8)
        except Exception:
            time.sleep(3)


def start(on_decision):
    if enabled():
        threading.Thread(target=_poll, args=(on_decision,), daemon=True).start()
```
**Important:** do NOT add a Telegram *Trigger* node in n8n for the same bot; two consumers of `getUpdates` conflict. n8n only uses **Send Message** nodes.

## 6. n8n: node by node

Run n8n (Docker):
```bash
docker run -d --name lazarus-n8n -p 5678:5678 -e N8N_SECURE_COOKIE=false \
  --add-host=host.docker.internal:host-gateway -v n8n_data:/home/node/.n8n n8nio/n8n
```
Open `http://localhost:5678`. Create these credentials: **Header Auth** for GitHub (`Authorization: Bearer <token>`), **Telegram** (bot token).

**Why polling and not a GitHub webhook:** a GitHub webhook needs a public HTTPS URL, which means a tunnel (ngrok/cloudflared) on conference Wi-Fi. A **10-second poll** needs nothing public and costs about 360 API calls an hour, far below the rate limit. Use polling as the default; a webhook through a tunnel is an optional upgrade.

| # | Node | Settings |
|---|---|---|
| 1 | **Schedule Trigger** | Every 10 seconds |
| 2 | **HTTP Request** "GitHub: latest failed run" | GET `https://api.github.com/repos/<you>/campus-api-demo/actions/runs?branch=main&status=failure&per_page=1`; Header Auth credential; header `Accept: application/vnd.github+json` |
| 3 | **Code** "Is it new?" | JavaScript, below |
| 4 | **Telegram** "Detected" | Send Message; chat id; text below |
| 5 | **HTTP Request** "Start Lazarus" | POST `http://host.docker.internal:8100/incident/start`; JSON body `{"run_id": {{ $('Code').item.json.run_id }}}` |
| 6 | **Wait** | 6 seconds |
| 7 | **HTTP Request** "Check status" | GET `http://host.docker.internal:8100/incident/{{ $('Start Lazarus').item.json.incident_id }}/status` |
| 8 | **IF** | `{{ $json.status }}` is one of `resolved`, `escalated`; the **false** branch loops back to node 6 |
| 9 | **Switch** | on `{{ $json.status }}`: `resolved` and `escalated` |
| 10 | **Telegram** "Result" (one per branch) | resolved: "✅ Fixed. Pipeline green again"; escalated: "🆘 Escalated: {{ $json.summary }}" |

- Lazarus's own merge produces a *passing* run on `main`, so it never re-triggers the flow.

| LLM rewrites a whole file badly | Validate non-empty / similar size; CI itself rejects a bad fix; two retries, then escalate |
